## Method

Similarity: 3-word shingles, Jaccard, threshold 0.7. Search: **minhash-lsh** over 7008 candidate pairs.

LSH generates candidates only; every reported pair is verified with the true Jaccard score, so similarity values mean the same thing as under exact search. Recall is not guaranteed - a small number of genuine near-duplicates may be missed, which makes these counts a lower bound.
