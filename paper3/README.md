# Paper 3 — Most Hosted Demos Are Broken

A census of the complete public Hugging Face Spaces catalogue: 1,458,692 Spaces
from 778,898 authors, retrieved 28 August 2026.

Headline: excluding static Spaces (which cannot fail), 38.57% of the 1,150,413
hosted applications are permanently broken and 2.85% are running.

Every figure recomputes from the collected CSV. Build the PDF on
https://overleaf.com or with `pdflatex`.
